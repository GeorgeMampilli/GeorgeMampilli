# Task Notepad

A simple, dependency-free notepad for keeping track of tasks. It's one HTML file: open `index.html` in any browser.

## Features

- Add tasks with notes, a priority (low / medium / high), and an optional due date
- Mark tasks done, edit them in place, or delete them
- Filter by All / Active / Done, search the text, and sort by newest, due date, or priority
- Highlights overdue tasks and shows counts at the top
- Light and dark themes
- Export your tasks to a JSON file and import them back (handy for backups or moving to another device)

## Where data is stored

Tasks are saved in your browser's `localStorage`, so they stay on that browser and device. Use **Export** to back them up.
